# College Companion

## Overview
College Companion is a web application designed to help students organize their academic activities in one place.

## Features
- Timetable Management
- Attendance Tracking
- Assignment Reminder
- Notices
- Responsive User Interface
- Data stored using Local Storage

## Tech Stack
- HTML
- CSS
- JavaScript

## Tools Used
- Visual Studio Code
- GitHub

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a web browser.

## Project Outcome
The application helps students efficiently manage daily academic tasks through a simple and user-friendly interface.
